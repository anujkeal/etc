# ETC — Project To-do List

Use this file as the working checklist for building the channel and producing the first four weeks of videos.

**How to use:** Tick an item by changing `[ ]` to `[x]`. Keep tasks specific and update this file as work progresses.

## 7. Review and improve

- [ ] Review audience retention for each main video.
- [ ] Read comments and identify points viewers found confusing.
- [ ] Record which explanations and visuals worked best.
- [ ] Review the time spent researching, scripting, recording, and editing.
- [ ] Identify one improvement for the next episode.
- [ ] Choose the next four topics based on audience questions, research quality, and production capacity.

## Rules for marking work complete

- A script is not complete until its important claims have been checked.
- A video is not ready until the explanation is understandable to a non-specialist.
- A visual should clarify the idea, not merely decorate the screen.
- A published video should include sources and appropriate credits.
- Do not mark a task complete just because a draft exists; check the actual deliverable.

---

**Priority:** Build the channel foundation, then complete Week 1. Work on one episode at a time while keeping the next topic's research lightweight.

**ETC principle:** Complex ideas. Clear explanations. Original stories.
